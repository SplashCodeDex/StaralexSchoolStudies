# Grade 7 Mathematics — Curriculum Tracker (NaCCA CCP / JHS 1)

Source: official NaCCA Common Core Programme JHS 1–3 Mathematics (2023 PDF, downloaded `curriculum/CCP-JHS/CCP_Mathematics_JHS.pdf`).
Codes are `B7.*` (Grade 7 = JHS 1 = Basic 7).

## How this tracker is ordered (NOT literal NaCCA page order)

Learning order is **pedagogical**: each step must be usable before the next.
Strand 1 (Number) is taught as **four sub-strands**, sequenced so nothing is used before it is built.

| Teach order | Sub-strand | Why this position |
| :---: | :--- | :--- |
| 1 | **Number and Numeration Systems** | Place value and big numbers are the foundation everything else stands on. |
| 2 | **Number Operations** | Mental + written calculations need numeration first. Indices are last inside this block (pure abstraction). |
| 3 | **Fractions, Decimals and Percentages** | Needs operations to add/subtract/multiply/divide the parts. |
| 4 | **Ratio and Proportion** | Needs both operations and fraction sense. |

Inside Number Operations the internal order is: **mental maths & powers of 10 → written four operations → decimals in operations → indices (as a new way to write repeated multiplication)**.
