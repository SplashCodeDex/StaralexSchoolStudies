## 1. What this lesson is about

A **fraction** is a way to write part of a whole: $\frac{3}{8}$ means 3 parts, each one eighth.

This lesson covers three faces of the same idea:

| Face | Example |
| :--- | :--- |
| Fraction | $\frac{1}{2}$ |
| Decimal | 0.5 |
| Percentage | 50% |

**Words to unpack first:**

| Word | Meaning |
| :--- | :--- |
| **Numerator** | top number (how many parts we have) |
| **Denominator** | bottom number (how many equal parts the whole was cut into) |
| **Percentage** | "out of 100" |
| **Benchmark fractions** | halves, thirds, quarters, fifths, eighths, tenths |
| **Common denominator** | the same bottom number |
| **LCM** | lowest common multiple — the smallest shared multiple of the denominators |

## 2. Benchmark equivalences (B7.1.3.1.1)

Learn these cold — they make everything else faster:

| Fraction | Decimal | Percentage |
| :---: | :---: | :---: |
| $\frac{1}{2}$ | 0.5 | 50% |
| $\frac{1}{4}$ | 0.25 | 25% |
| $\frac{3}{4}$ | 0.75 | 75% |
| $\frac{1}{5}$ | 0.2 | 20% |
| $\frac{1}{8}$ | 0.125 | 12.5% |
| $\frac{1}{3}$ | 0.333… | 33⅓% |
| $\frac{1}{10}$ | 0.1 | 10% |

**Converting:**
- Fraction → decimal: **divide top by bottom** ($\frac{3}{8} = 3 \div 8 = 0.375$).
- Decimal → percentage: **multiply by 100** (0.375 → 37.5%).
- Percentage → fraction: **divide by 100**, then simplify (37.5% = 37.5/100 = 3/8).

## 3. Compare and order (B7.1.3.1.2)

**Same denominator:** bigger numerator wins ($\frac{5}{8} > \frac{3}{8}$).

**Different denominators:** use a common denominator (LCM).

**Example:** order $\frac{3}{8}, \frac{1}{2}, \frac{5}{16}$.
LCM of 8, 2, 16 is 16.

$$\frac{3}{8} = \frac{6}{16}, \quad \frac{1}{2} = \frac{8}{16}, \quad \frac{5}{16} = \frac{5}{16}$$

Order: $\frac{5}{16} < \frac{3}{8} < \frac{1}{2}$.

**Cross-multiply shortcut:** to compare $\frac{a}{b}$ and $\frac{c}{d}$, compare $ad$ and $cb$.

---

## 4. Add and subtract fractions (B7.1.3.2)

You **must** have the same denominator.

$$\frac{1}{3} + \frac{1}{4} = \frac{4}{12} + \frac{3}{12} = \frac{7}{12}$$

**Mixed numbers:** convert to improper fractions first.

$$2\frac{1}{2} - \frac{1}{3} = \frac{5}{2} - \frac{1}{3} = \frac{15-2}{6} = \frac{13}{6} = 2\frac{1}{6}$$

**Word problem (B7.1.3.2.2):** Amina had $2\frac{1}{2}$ litres and drank $\frac{1}{3}$ litres. Left? → $2\frac{1}{6}$ litres.

---

## 5. Multiply fractions (B7.1.3.3.1–3.2)

Top × top, bottom × bottom (cancel first if you can):

$$\frac{2}{3} \times \frac{1}{4} = \frac{2}{12} = \frac{1}{6}$$

**Fraction of a quantity:**

$$\frac{3}{8} \text{ of } 480 = \frac{3}{8} \times 480 = 180$$

---

## 6. Divide fractions (B7.1.3.3.3–3.4)

**Keep, Change, Flip** (multiply by the reciprocal):

$$\frac{2}{5} \div \frac{14}{15} = \frac{2}{5} \times \frac{15}{14} = \frac{30}{70} = \frac{3}{7}$$

**Dividing a quantity:** How many $\frac{1}{4}$-litre cups in 3 litres?
$$3 \div \frac{1}{4} = 3 \times 4 = 12 \text{ cups}$$

## 7. Twenty fully worked examples

1. $\frac{1}{2} = 0.5 = 50\%$.  
2. $\frac{3}{8} = 0.375 = 37.5\%$.  
3. $0.25 = \frac{1}{4} = 25\%$.  
4. $12.5\% = 0.125 = \frac{1}{8}$.  
5. Order $\frac{3}{8}, \frac{1}{2}, \frac{5}{16}$ → $\frac{5}{16} < \frac{3}{8} < \frac{1}{2}$.  
6. $\frac{3}{8} + \frac{1}{8} = \frac{1}{2}$.  
7. $\frac{1}{3} + \frac{1}{4} = \frac{7}{12}$.  
8. $\frac{5}{6} - \frac{1}{4} = \frac{7}{12}$.  
9. $2\frac{1}{2} - \frac{1}{3} = 2\frac{1}{6}$.  
10. $\frac{2}{3} \times \frac{1}{4} = \frac{1}{6}$.  
11. $\frac{3}{8}$ of 480 = 180.  
12. 35% of GH₵ 240 = 84.  
13. $\frac{2}{5} \div \frac{14}{15} = \frac{3}{7}$.  
14. $3 \div \frac{1}{4} = 12$ cups.  
15. $\frac{1}{2}$ of $\frac{3}{5} = \frac{3}{10}$.  
16. Convert $2\frac{1}{2}$ to improper → $\frac{5}{2}$.  
17. Convert $\frac{11}{4}$ to mixed → $2\frac{3}{4}$.  
18. 45% vs $\frac{9}{20}$: $\frac{9}{20} = 45\%$ → equal.  
19. $\frac{1}{2} + \frac{1}{3} \times \frac{3}{4} = \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$ (BODMAS).  
20. $\left(\frac{1}{2} + \frac{1}{3}\right) \times \frac{6}{5} = \frac{5}{6} \times \frac{6}{5} = 1$.
