## Preamble (pre-lesson)

Before the questions, here is the big picture.

A **computer** is a machine that takes data in, works on it, and gives results out.

```
   [INPUT]  ──▶  [COMPUTER / STORAGE]  ──▶  [OUTPUT]
  keyboard        the machine itself          monitor
  mouse           keeps your files            printer
  scanner         runs the programs           speakers
```

Everything below is built on this one idea: **in → process/store → out**.

## A. Generations of computers

**Q1.** What is a computer?  
**Ans.** A computer is a machine that takes data in, processes it, and gives results out.

**Q2.** What is hardware?  
**Ans.** Hardware is any physical part of a computer you can touch.

**Q3.** What is software?  
**Ans.** Software is the set of programs that tell the hardware what to do.

**Q4.** What is a generation of computers?  
**Ans.** A generation is a stage in computer history marked by the technology used to build it.

**Q5.** How many main generations of computers are there?  
**Ans.** There are four main generations.

**Q6.** What technology marked the first generation of computers?  
**Ans.** The first generation used vacuum tubes.

**Q7.** What technology marked the second generation of computers?  
**Ans.** The second generation used transistors.

**Q8.** What technology marked the third generation of computers?  
**Ans.** The third generation used integrated circuits (chips).

**Q9.** What technology marked the fourth generation of computers?  
**Ans.** The fourth generation used the microprocessor.

**Q10.** What is a microprocessor?  
**Ans.** A microprocessor is a whole central processing unit built onto a single small chip.

**Q11.** Which generation do today's laptops and phones belong to?  
**Ans.** Today's laptops and phones belong to the fourth generation.

**Q12.** Why is the fourth generation important?  
**Ans.** It is important because it made computers small, cheap, and fast enough for everyday use.

## B. Input devices

**Q13.** What is an input device?  
**Ans.** An input device is a tool that puts data into a computer.

**Q14.** Mention five examples of input devices.  
**Ans.**
- Keyboard
- Mouse
- Barcode scanner
- Microphone
- Webcam

**Q15.** What does a keyboard do?  
**Ans.** A keyboard lets you type letters, numbers, and commands into the computer.

**Q16.** What does a mouse do?  
**Ans.** A mouse lets you point at and select things on the screen.

**Q17.** What does a barcode scanner do?  
**Ans.** A barcode scanner reads the striped code printed on a product.

**Q18.** Where do people use barcode scanners?  
**Ans.** People use barcode scanners in shops, supermarkets, and libraries.

**Q19.** What does a QR code scanner do?  
**Ans.** A QR code scanner reads a square black-and-white code to open information quickly.

**Q20.** What does a microphone do?  
**Ans.** A microphone captures sound and sends it into the computer.

**Q21.** What does a webcam do?  
**Ans.** A webcam captures pictures and video for the computer.

**Q22.** What does a scanner do?  
**Ans.** A scanner copies a paper document into a digital file.

**Q23.** What is a touchscreen?  
**Ans.** A touchscreen is a screen that also accepts taps and touches as input.

**Q24.** State the types of common input devices used in a school computer lab.  
**Ans.**
- Keyboard
- Mouse
- Scanner
- Microphone
- Webcam

## C. Output devices

**Q25.** What is an output device?  
**Ans.** An output device is a tool that shows or produces the results from a computer.

**Q26.** Mention five examples of output devices.  
**Ans.**
- Monitor
- Printer
- Speakers
- Graphing plotter
- Data projector

**Q27.** What does a monitor do?  
**Ans.** A monitor displays pictures and text you can see.

**Q28.** What does a printer do?  
**Ans.** A printer produces paper copies of digital documents.

**Q29.** What do speakers do?  
**Ans.** Speakers produce sound from the computer.

**Q30.** What does a graphing plotter do?  
**Ans.** A graphing plotter draws large and very precise pictures such as maps and engineering drawings.

**Q31.** What does a data projector do?  
**Ans.** A data projector shows a large image on a wall or screen.

**Q32.** What does a 3D printer do?  
**Ans.** A 3D printer builds a solid object from a digital design.

## D. Storage devices

**Q33.** What is storage?  
**Ans.** Storage is the place where a computer keeps data until it is needed.

**Q34.** What is an external storage device?  
**Ans.** An external storage device is a storage tool you can plug in and carry with you.

**Q35.** Mention five types of storage devices.  
**Ans.**
- Full-sized external hard drive
- Hard disk drive (HDD)
- Solid-state drive (SSD)
- USB flash drive
- Memory card

**Q36.** What is a hard disk drive (HDD)?  
**Ans.** A hard disk drive is a storage device that uses spinning disks inside it.

**Q37.** What is a solid-state drive (SSD)?  
**Ans.** A solid-state drive is a storage device with no moving parts that is faster and quieter than a hard disk.

**Q38.** What is a USB flash drive?  
**Ans.** A USB flash drive is a small portable storage device that plugs into a USB port.

**Q39.** What is a memory card used for?  
**Ans.** A memory card stores data in cameras, phones, and some computers.

**Q40.** Which is faster, an HDD or an SSD?  
**Ans.** An SSD is faster than an HDD.

## E. The operating system and Windows

**Q41.** What is an operating system?  
**Ans.** An operating system is the main software that runs the computer and manages all other programs.

**Q42.** Give one example of an operating system.  
**Ans.** Windows is one example of an operating system.

**Q43.** What is the Start button in Windows used for?  
**Ans.** The Start button opens programs, search, settings, and power options.

**Q44.** How do you search for a program in Windows?  
**Ans.** You click Start and type the name of the program.

**Q45.** Where do you change the wallpaper in Windows?  
**Ans.** You change the wallpaper in Settings under Personalisation.

**Q46.** What does the Power option in Windows do?  
**Ans.** The Power option lets you Sleep, Shut down, or Restart the computer.

**Q47.** What does "Shut down" do?  
**Ans.** Shut down turns the computer completely off.

**Q48.** What does "Restart" do?  
**Ans.** Restart turns the computer off and immediately back on again.

## F. Files and folders

**Q49.** What is a file?  
**Ans.** A file is a named collection of data such as a document, photo, or video.

**Q50.** What is a folder?  
**Ans.** A folder is a container that holds files and other folders.

**Q51.** What is file management?  
**Ans.** File management is the skill of creating, naming, moving, and finding your files.

**Q52.** Why should a file have a meaningful name?  
**Ans.** A meaningful name helps you find the file again later.

**Q53.** Give one good example of a file name.  
**Ans.** Maths_Homework_Week3.docx is one good example of a file name.

**Q54.** Give one bad example of a file name.  
**Ans.** doc1.docx is one bad example of a file name.

**Q55.** How do you create a new folder?  
**Ans.** You right-click, choose New, and then choose Folder.

**Q56.** How do you rename a file?  
**Ans.** You right-click the file and choose Rename.

**Q57.** What is the keyboard shortcut for Copy?  
**Ans.** The keyboard shortcut for Copy is Ctrl + C.

**Q58.** What is the keyboard shortcut for Paste?  
**Ans.** The keyboard shortcut for Paste is Ctrl + V.

**Q59.** What is the keyboard shortcut for Cut?  
**Ans.** The keyboard shortcut for Cut is Ctrl + X.

**Q60.** What is the difference between Cut and Copy?  
**Ans.** Cut removes the file from its original place while Copy leaves the original in place.

**Q61.** What happens when you press Delete on a file?  
**Ans.** The file goes to the Recycle Bin.

**Q62.** How do you restore a file from the Recycle Bin?  
**Ans.** You open the Recycle Bin, right-click the file, and choose Restore.

**Q63.** How do you search for a lost file in Windows?  
**Ans.** You open Start and type the file name in the search box.
