## 2. Preamble — What a Fraction Really Is

A fraction $\frac{a}{b}$ answers one question: **"how many equal parts of size $\frac{1}{b}$ do we have?"**

- **Numerator** (top): how many parts we have.
- **Denominator** (bottom): how many equal parts the whole was cut into.

So $\frac{3}{8}$ means 3 pieces, each one eighth of a whole.

**Mixed number:** a whole number plus a fraction, e.g. $2\frac{1}{2}$ (two and a half).  
**Improper fraction:** top ≥ bottom, e.g. $\frac{5}{2}$.

> Convert mixed → improper: $2\frac{1}{2} = \frac{2 \times 2 + 1}{2} = \frac{5}{2}$.  
> Convert improper → mixed: $\frac{7}{3} = 2\frac{1}{3}$ (because 7 ÷ 3 = 2 remainder 1).

## 3. Comparing and Ordering Fractions

### 3.1 Same denominator
Bigger numerator wins: $\frac{5}{8} > \frac{3}{8}$.

### 3.2 Different denominators — use a common denominator
To compare $\frac{3}{8}, \frac{1}{2}, \frac{5}{16}$:  
LCM of 8, 2, 16 is **16**.

$$\frac{3}{8} = \frac{6}{16}, \quad \frac{1}{2} = \frac{8}{16}, \quad \frac{5}{16} = \frac{5}{16}$$

So $\frac{5}{16} < \frac{3}{8} < \frac{1}{2}$. *(This is Mock P1 Q26 — option C.)*

### 3.3 Cross-multiplication shortcut
To compare $\frac{a}{b}$ and $\frac{c}{d}$, compare $ad$ and $cb$.  
$\frac{3}{8}$ vs $\frac{1}{2}$: $3 \times 2 = 6$, $1 \times 8 = 8$. Since $6 < 8$, we have $\frac{3}{8} < \frac{1}{2}$.

---

## 4. The Four Operations

### 4.1 Addition / subtraction
**Need the same denominator** (use the LCM).

$$\frac{a}{b} + \frac{c}{b} = \frac{a+c}{b}$$

$$\frac{1}{3} + \frac{1}{4} = \frac{4}{12} + \frac{3}{12} = \frac{7}{12}$$

### 4.2 Multiplication
Multiply top × top, bottom × bottom (cancel first if you can):

$$\frac{2}{3} \times \frac{1}{4} = \frac{2}{12} = \frac{1}{6}$$

### 4.3 Division
**Keep, Change, Flip** (multiply by the reciprocal):

$$\frac{2}{5} \div \frac{14}{15} = \frac{2}{5} \times \frac{15}{14} = \frac{30}{70} = \frac{3}{7}$$

### 4.4 Mixed numbers
Convert to improper fractions first.

$$2\frac{1}{2} - \frac{1}{3} = \frac{5}{2} - \frac{1}{3} = \frac{15}{6} - \frac{2}{6} = \frac{13}{6} = 2\frac{1}{6}$$

## 5. BODMAS with Fractions

Order of operations:

1. **B**rackets  
2. **O**rders (powers, roots)  
3. **D**ivision and **M**ultiplication (left to right)  
4. **A**ddition and **S**ubtraction (left to right)

**Mock P2 Q4(c):** $\frac{2}{3} \times \frac{1}{4} + \frac{2}{5} \div \frac{14}{15}$

1. Multiplication and division **before** addition:  
   $\frac{2}{3} \times \frac{1}{4} = \frac{2}{12} = \frac{1}{6}$  
   $\frac{2}{5} \div \frac{14}{15} = \frac{2}{5} \times \frac{15}{14} = \frac{30}{70} = \frac{3}{7}$
2. Add: $\frac{1}{6} + \frac{3}{7} = \frac{7}{42} + \frac{18}{42} = \frac{25}{42}$.

**Answer:** $\frac{25}{42}$.

## 6. Fractions ↔ Decimals ↔ Percentages

| Fraction | Decimal | Percentage |
| :---: | :---: | :---: |
| 1/2 | 0.5 | 50% |
| 1/4 | 0.25 | 25% |
| 3/4 | 0.75 | 75% |
| 1/5 | 0.2 | 20% |
| 1/8 | 0.125 | 12.5% |
| 1/3 | 0.333… | 33⅓% |
| 3/8 | 0.375 | 37.5% |
| 5/16 | 0.3125 | 31.25% |

**Convert:**  
- Fraction → decimal: divide top by bottom.  
- Decimal → percentage: × 100.  
- Percentage → fraction: ÷ 100, then simplify.

**Mock P1 Q12:** $\frac{n}{100} = 10.5 \Rightarrow n = 10.5 \times 100 = 1050$. **Answer: C.**

## 7. Twenty Fully Worked Examples

### Example 1 — Mixed to improper
$2\frac{1}{2} = \frac{5}{2}$.

### Example 2 — Improper to mixed
$\frac{11}{4} = 2\frac{3}{4}$.

### Example 3 — Add same denominator
$\frac{3}{8} + \frac{1}{8} = \frac{4}{8} = \frac{1}{2}$.

### Example 4 — Add different denominators
$\frac{1}{3} + \frac{1}{4} = \frac{4+3}{12} = \frac{7}{12}$.

### Example 5 — Subtract fractions
$\frac{5}{6} - \frac{1}{4} = \frac{10}{12} - \frac{3}{12} = \frac{7}{12}$.

### Example 6 — Multiply fractions
$\frac{2}{3} \times \frac{1}{4} = \frac{2}{12} = \frac{1}{6}$.

### Example 7 — Divide fractions
$\frac{2}{5} \div \frac{14}{15} = \frac{2}{5} \times \frac{15}{14} = \frac{3}{7}$.

### Example 8 — Mock P2 Q2(a)(i): Amina's water
$2\frac{1}{2} - \frac{1}{3} = \frac{5}{2} - \frac{1}{3} = \frac{15-2}{6} = \frac{13}{6} = 2\frac{1}{6}$ litres.

### Example 9 — Mock P2 Q4(c): BODMAS
$\frac{2}{3} \times \frac{1}{4} + \frac{2}{5} \div \frac{14}{15} = \frac{1}{6} + \frac{3}{7} = \frac{25}{42}$.

### Example 10 — Mock P1 Q26: order fractions
$\frac{5}{16} = \frac{5}{16}$; $\frac{3}{8} = \frac{6}{16}$; $\frac{1}{2} = \frac{8}{16}$.  
Order: $\frac{5}{16} < \frac{3}{8} < \frac{1}{2}$ → **C**.

### Example 11 — Mock P1 Q12: n/100 = 10.5
$n = 1050$ → **C**.

### Example 12 — Fraction of a quantity
$\frac{3}{8}$ of 480 = $\frac{3}{8} \times 480 = 180$.

### Example 13 — Percentage of a quantity
35% of GH₵ 240 = $0.35 \times 240 = 84$.

### Example 14 — Convert 0.375 to a percentage
$0.375 \times 100 = 37.5\%$.

### Example 15 — Convert 12.5% to a fraction
$12.5\% = \frac{12.5}{100} = \frac{1}{8}$.

### Example 16 — Fraction of a fraction
$\frac{1}{2}$ of $\frac{3}{5} = \frac{1}{2} \times \frac{3}{5} = \frac{3}{10}$.

### Example 17 — Share in a ratio (preview of L5)
Share GH₵ 720 in the ratio 2:3.  
Total parts $= 5$. One part $= 144$. Shares: $288$ and $432$.

### Example 18 — BODMAS with mixed ops
$\frac{1}{2} + \frac{1}{3} \times \frac{3}{4} = \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$ (multiply first).

### Example 19 — Word problem: remaining litres
A tank holds $5\frac{1}{4}$ litres. $1\frac{1}{2}$ litres leak out. How much remains?  
$\frac{21}{4} - \frac{3}{2} = \frac{21}{4} - \frac{6}{4} = \frac{15}{4} = 3\frac{3}{4}$ litres.

### Example 20 — Word problem: class fractions
In a class of 40 pupils, $\frac{3}{8}$ are girls. How many boys?  
Girls $= 15$; boys $= 25$.
