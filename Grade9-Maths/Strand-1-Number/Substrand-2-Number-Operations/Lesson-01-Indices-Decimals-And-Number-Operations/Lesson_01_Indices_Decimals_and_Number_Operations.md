## 3. Indices (Powers)

### 3.1 What a power means

$$a^n = \underbrace{a \times a \times \cdots \times a}_{n \text{ times}}$$

- $a$ is the **base**.
- $n$ is the **index** (or exponent / power).

**Examples:** $3^4 = 3 \times 3 \times 3 \times 3 = 81$; $5^2 = 25$; $2^5 = 32$.

### 3.2 The three laws you must know

| Law | Rule | Example |
| :--- | :--- | :--- |
| Multiplication | $a^m \times a^n = a^{m+n}$ | $2^3 \times 2^4 = 2^7 = 128$ |
| Division | $a^m \div a^n = a^{m-n}$ | $5^6 \div 5^2 = 5^4 = 625$ |
| Power of a power | $(a^m)^n = a^{mn}$ | $(3^2)^3 = 3^6 = 729$ |

Also useful:
- $a^0 = 1$ (any non-zero base).
- $a^{-n} = \frac{1}{a^n}$ (negative index = flip the fraction).
- $(ab)^n = a^n b^n$; $\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$.

### 3.3 Different faces of the same number

$3^6$ can be rewritten many ways:
- $3^6 = 729$
- $3^6 = (3^2)^3 = 9^3$
- $3^6 = (3^3)^2 = 27^2$
- $3^6 = 3^3 \times 3^3 = 27 \times 27$

**What it is NOT:** $3^6 \ne 18$ (18 is $3 \times 6$, which is multiplication, not a power).

### 3.4 Solving equations with indices (same base)

If $a^m = a^n$ and $a \ne 0, 1, -1$, then $m = n$.

**Example:** $2^{x+1} = 2^5 \Rightarrow x + 1 = 5 \Rightarrow x = 4$.

**Watch the base:** $(-3)^{x-2} = -243$.  
First write $-243$ as a power of $-3$:  
$(-3)^1 = -3$, $(-3)^2 = 9$, $(-3)^3 = -27$, $(-3)^4 = 81$, $(-3)^5 = -243$.  
So $x - 2 = 5 \Rightarrow x = 7$.

### 3.5 Changing the base

$4^{14} = (2^2)^{14} = 2^{28}$.  
If population $= 2^{2m}$ and we want it equal to $4^{14} = 2^{28}$, then $2m = 28 \Rightarrow m = 14$ years.

## 4. Decimal Operations

### 4.1 Golden rule — line up the decimal points

**Addition / subtraction:** put the decimal points in one column.

```
  124.3
    0.275
+  74.06
--------
  198.635
```

### 4.2 Multiplication of decimals

1. Multiply as if they were whole numbers.
2. Count the **total** number of decimal places in the factors.
3. Put that many decimal places in the answer.

**Example:** $0.07 \times 0.02$.  
Whole numbers: $7 \times 2 = 14$.  
Decimal places: 2 + 2 = 4.  
So $0.07 \times 0.02 = 0.0014$.

### 4.3 Division of decimals

1. Make the divisor a whole number by moving its decimal point.
2. Move the dividend's decimal point the **same** number of places.
3. Divide as usual.

**Example:** $(0.07 \times 0.02) \div 14 = 0.0014 \div 14 = 0.0001$.

### 4.4 Rounding the final answer

Word problems often say "correct to 1 d.p.", "2 s.f.", etc. Round **only at the end**, never in the middle steps (unless told to).

## 5. Distributive Property & Equal Grouping

$$a(b + c) = ab + ac$$

**Sharing equally:** if $n$ items go into packets of size $k$, the number of packets is $n \div k$ (and we usually want a **whole number** of packets).

**Example:** 12 identical cakes into equal packets. Packet sizes that work: 2, 3, 4, 6, 12 → **5 ways** (if we require more than one packet and more than one cake per packet? — see worked examples; BECE usually counts distinct divisors except 1 and itself when it says "equal packets" of size > 1).

## 6. Twenty Fully Worked Examples

### Example 1 — Powers of 10
$47 \times 100 = 4\,700$.  
$0.56 \div 1000 = 0.00056$.

### Example 2 — Multiply indices
$2^3 \times 2^4 = 2^{7} = 128$.

### Example 3 — Divide indices
$5^6 \div 5^2 = 5^{4} = 625$.

### Example 4 — Power of a power
$(3^2)^3 = 3^{6} = 729$.

### Example 5 — Mock P1 Q9: which is NOT $3^6$?
$3^6 = 729$; $9^3 = 729$; $18 \ne 729$.  
**Answer: B — 18.**

### Example 6 — Negative index
$2^{-3} = \frac{1}{2^3} = \frac{1}{8} = 0.125$.

### Example 7 — Zero index
$7^0 = 1$.

### Example 8 — Mock P2 Q7(c)(i): $(-3)^{x-2} = -243$
$(-3)^5 = -243 \Rightarrow x - 2 = 5 \Rightarrow x = 7$.

### Example 9 — Mock P2 Q7(c)(ii): $11^{4x-3}$ at $x = 2$
$4(2) - 3 = 5$, so $11^5 = 161\,051$.  
To 4 s.f.: $1.611 \times 10^{5}$ (or 161 100).

### Example 10 — Mock P1 Q33: $2^{2m} = 4^{14}$
$4^{14} = (2^2)^{14} = 2^{28}$. So $2m = 28 \Rightarrow m = 14$ years.  
**Answer: C — 14.**

### Example 11 — Mock P1 Q1: decimal addition
$124.3 + 0.275 + 74.06 = 198.635$.  
To 1 d.p.: **198.6**. **Answer: A.**

### Example 12 — Mock P1 Q14: $(0.07 \times 0.02) \div 14$
$0.07 \times 0.02 = 0.0014$; $0.0014 \div 14 = 0.0001$. **Answer: C.**

### Example 13 — Mock P1 Q32: 112 flies at 0.1 kg
$112 \times 0.1 = 11.2$ kg. **Answer: C.**

### Example 14 — Mock P1 Q40: 12 cakes into equal packets
Divisors of 12 (packet sizes > 1): 2, 3, 4, 6, 12 → **5 ways** if we count all equal-packet sizes except 1.  
*(BECE official answer is C = 6 — which counts packet sizes 2, 3, 4, 6, 12 **and** the case of packets of 1, i.e. all 6 proper divisor-style splits 12÷1, 12÷2, 12÷3, 12÷4, 12÷6, 12÷12. Always read whether "equal packets" excludes trivial splits.)*

### Example 15 — Long division with decimals
$4.86 \div 0.3$: move both decimals one place → $48.6 \div 3 = 16.2$.

### Example 16 — Word problem: shopping
A shirt costs GH₵ 47.50. Kofi buys 3 shirts and pays with GH₵ 200. Change = ?
$3 \times 47.50 = 142.50$. Change $= 200 - 142.50 = 57.50$.

### Example 17 — Word problem: time (Mock P2 Q5b style)
11:13 am → 3:08 pm.
11:13 → 12:00 = 47 min; 12:00 → 3:00 = 3 h; 3:00 → 3:08 = 8 min.  
Total $= 3$ hours $55$ minutes.

### Example 18 — Rate problem preview
20 gallons per minute for 30 minutes: $20 \times 30 = 600$ gallons. *(Full treatment in Lesson 5.)*

### Example 19 — Distributive shortcut
$7 \times 102 = 7(100 + 2) = 700 + 14 = 714$.

### Example 20 — Mixed ops with BODMAS
$48 \div 6 + 5 \times 2 - 3 = 8 + 10 - 3 = 15$.
